# Ejemplos de Markdown en Chat

## Características soportadas:

### 1. Títulos y subtítulos
Los títulos se renderizan con diferentes tamaños y pesos.

### 2. Formato de texto
- **Texto en negrita**
- *Texto en cursiva*
- ~~Texto tachado~~

### 3. Listas
- Elemento 1
- Elemento 2
  - Subelemento 2.1
  - Subelemento 2.2

Lista numerada:
1. Primer elemento
2. Segundo elemento
3. Tercer elemento

### 4. Código
Código inline: `console.log("Hola mundo")`

Bloque de código:
```javascript
function saludar(nombre) {
    return `Hola, ${nombre}!`;
}

console.log(saludar("Usuario"));
```

### 5. Citas
> Esta es una cita importante
> que puede abarcar múltiples líneas.

### 6. Tablas
| Columna 1 | Columna 2 | Columna 3 |
|-----------|-----------|-----------|
| Dato 1    | Dato 2    | Dato 3    |
| Dato 4    | Dato 5    | Dato 6    |
